# Pesquisa de Opiniao em Python
---
## 📋 Visao Geral do Codigo

O programa tem como objetivo realizar uma **pesquisa de opiniao** com **10 pessoas**. Ele coleta dados de cada participante (nome, idade e opiniao sobre um atendimento) e contabiliza quantas respostas foram classificadas como **RUIM**, **EXCELENTE** ou **BOM**. No final, exibe o resumo dos resultados.
